# 图像滤波实验台

这是一个离线运行的图像滤波可视化实验项目，直接用浏览器打开 `index.html` 即可使用，不依赖 Python、Node 或第三方包。

## 已实现内容

- 空间域滤波：Box 均值、高斯、中值、Sobel X/Y/幅值、Laplacian、锐化。
- 滤波对比：展示输出图、运行耗时、平均绝对差、标准差，并横向比较常见滤波器。
- 梯度方向演示：可上传图像并框选局部区域，计算 Sobel 梯度 `Gx/Gy`、平均方向、幅值加权主方向，并绘制方向直方图。
- 频率域滤波：基于 2D FFT/IFFT，绘制中心化对数频谱，支持理想低通/高通、高斯低通/高通、带通、带阻滤波。
- 谱图变化比较：展示图像在旋转、循环平移、缩放后的空间图与频谱图，并给出频谱相关系数。

## 运行方式

在文件管理器中双击打开：

```text
index.html
```

或者在浏览器地址栏打开该文件路径。

## 实验观察

- Box 和 Gaussian 会抑制高频细节，频域表现为保留中心低频区域。
- Median 对椒盐类噪声更稳健，因为它不是线性卷积。
- Sobel 通过 `atan2(Gy, Gx)` 得到梯度方向，幅值越大代表灰度变化越强。
- 平移会改变傅里叶相位，理论上不改变幅度谱；本项目的循环平移可直接观察到这一点。
- 旋转会让幅度谱随之旋转；缩放会让空间域和频域呈反向尺度变化。
